# Visual comparison protocol

Use the original, neutral registration, previous accepted candidate if one exists, and the current candidate at a fixed reference scale and ground. Do not resize each frame to its own bounding box. Explicitly label any requested change in proportions.

Inspect every exported pose in normal color at native and intended game size, then examine joins over black, white, saturated cyan/magenta and checkerboard backgrounds. Review isolated layers, the complete garment perimeter, ink/antialias contours and both near/far shoulder roots. Skin interiors or small selected ROIs are not sufficient evidence.

For a continuous rig, include dense samples between the displayed keys and inspect support exchanges. For authored cels, inspect every actual drawing with its neighbors and true timing; repeated holds are not new intermediate drawings. Compare the last displayed frame to the first, without exporting a duplicate endpoint by default.

Record anatomy landmarks separately from observed visible boundaries. Hidden hip positions are inferences, not immutable facts. A source foot may be at a different projected depth plane from the other; screen Y alone does not establish ground contact.

Observe the exact loop at normal speed at both sizes before a temporal-quality claim. Tests, static sheets and encoded frame durations do not prove this observation. Record UNREVIEWED if real playback is unavailable. See `PRODUCTION_CHECKS.md` and the skill's `references/quality.md`.
